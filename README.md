# Aula 3D VR con Three.js y SketchUp

Proyecto de visualización 3D desarrollado con **Three.js**, **WebXR** y **SketchUp 2025**, permitiendo mostrar un modelo del aula **Y8** dentro de una página web interactiva con soporte VR.

---

# 📌 Objetivo

Desarrollar una aplicación web capaz de visualizar un modelo 3D exportado desde SketchUp utilizando:

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Three.js
* WebXR (VR)

---

# 🛠 Tecnologías utilizadas

| Tecnología    | Descripción                  |
| ------------- | ---------------------------- |
| HTML5         | Estructura de la página      |
| CSS3          | Estilos Cyberpunk/Futuristas |
| JavaScript    | Lógica de la aplicación      |
| Bootstrap 5   | Diseño responsivo            |
| Three.js      | Renderizado 3D               |
| WebXR         | Compatibilidad VR            |
| SketchUp 2025 | Modelado 3D                  |

# 🚀 Desarrollo del proyecto

## 1. Instalación de SketchUp 2025

* Descargar e instalar SketchUp 2025.
* Abrir el programa correctamente.

---

## 2. Creación del modelo 3D

Dentro de SketchUp:

* Crear el diseño 3D del aula Y8.
* Seguir las indicaciones y guía del docente.
* Agregar:

  * paredes
  * sillas
  * mesas
  * ventanas
  * mobiliario

---

## 3. Exportación del modelo

Exportar el modelo en formato:

```plaintext id="f03mql"
.glb
```

### ¿Por qué `.glb`?

Porque:

* es ligero
* optimizado para web
* compatible con Three.js
* conserva materiales y texturas
* compatible con VR/WebXR
